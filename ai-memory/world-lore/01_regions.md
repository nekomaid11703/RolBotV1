# Regiones del Mundo

_Archivo de lore por regiones. Cada región es una zona geográfica amplia. Edítalo para definir regiones._

## Template de Región

```markdown
### [Nombre de Región]
- **Tipo:** [bosque/desierto/ciudad/montaña/subterráneo/mar]
- **Peligrosidad:** [baja/media/alta/letal]
- **Gobierno:** [quién gobierna]
- **Habitantes:** [principales criaturas/razas]

**Descripción:**
_Ambiente, clima, historia local._

**Lugares de interés:**
- _Lugar 1_
- _Lugar 2_
```
