# Planning Skill

Use this skill for complex or multi-file work.

## Procedure

1. Investigate relevant files without changing code.
2. Check memory and the design board for existing decisions.
3. Define the goal, dependencies, risks, and validation plan.
4. Break execution into small tasks in `task.md`.
5. Keep the implementation aligned with existing project patterns.

## Required Outputs

- A concise plan or checklist.
- A clear list of files to touch.
- Validation commands or manual checks.
- Memory entries for durable decisions.

## Constraints

- Do not introduce new external services without evidence and credentials.
- Do not overwrite valid existing configuration.
- Do not assume Docker, Go, GitHub MCP, RAG, or vector databases are available.
